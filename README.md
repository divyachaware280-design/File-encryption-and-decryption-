**File Encryption & Decryption System using Python**

A Python-based cybersecurity project that securely encrypts and decrypts files using the AES-256-GCM encryption algorithm. It protects sensitive data from unauthorized access through password-based encryption. The system uses Scrypt for secure key generation and supports multiple file formats, including PDF, TXT, images, and documents. It also detects incorrect passwords and file tampering. A simple Windows batch launcher makes the system easy to use.
